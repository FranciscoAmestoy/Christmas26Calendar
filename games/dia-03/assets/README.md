# 🎨 Placeholders Gráficos (PNG) — Día 03: ¡Apuros en el Correo!

El juego incluye **gráficos vectoriales ilustrados (SVG) de alta calidad** integrados en el código (cero emojis del sistema) y el fondo generado `post_office_bg.jpg`.

Además, si querés reemplazar algún sobre o caja por un sprite `.png` propio, podés sobrescribir cualquiera de estos 8 archivos *placeholder*:
- `letter_red.png`, `letter_green.png`, `letter_gold.png`, `letter_blue.png` (Sobres arrastrables)
- `bin_red.png`, `bin_green.png`, `bin_gold.png`, `bin_blue.png` (Bandejas/cajas clasificadoras)
